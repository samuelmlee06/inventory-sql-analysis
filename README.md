# Inventory SQL Analysis

## Overview
This project demonstrates how SQL can be used to analyze retail inventory data using SQLite.

## Skills Used
- SQL
- SQLite
- Data filtering
- Aggregation
- GROUP BY
- ORDER BY
- SUM
- COUNT

## Example Analysis
- Calculate total inventory for a specific product style
- Compare inventory levels across brands
- Count products by brand
- Filter and summarize inventory data

## Dataset
The dataset included in this repository is a sanitized sample used for demonstration purposes. Inventory quantities and other sensitive values have been replaced with dummy data and do not reflect actual company information.
